# 03 统计图形分析

这里回答「手里有什么数据，要回答什么问题，用哪种图，图上的位置、长度或颜色又各代表什么」。从每张图背后的数据表出发，记录字段、计算与视觉选择。

| 位置 | 主要问题 |
|---|---|
| [01 信息图形数据逻辑](../01-信息图形数据逻辑/) | 整张信息图围绕哪种关系组织，例如时间、层级或类别？ |
| [02 信息图形类型案例](../02-信息图形类型案例/README.md) | 作品用了什么表现形式，怎样安排读图顺序？ |
| **03 统计图形分析** | 作品中这张图如何统计、怎样画，结论能支持到哪里？ |

例如 [香港历年降雨主图](../02-信息图形类型案例/10-单一图表型-Single-Chart/案例/CASE-012-香港历年降雨主图/分析.md) 在 01 属于编年型，在 02 可用单一图表型研究主图，在 03 则要说清逐日记录怎样变成按年的条形图，以及缺测的年份怎么标。

## 学习入口

1. [图表选择速查](./图表选择速查.md) 按想回答的问题找图，也能查需要哪些字段与容易看错的地方。
2. [统计图形分析模板](./统计图形分析模板.md) 用于记录数据粒度、统计口径、视觉编码、证据与限制。
3. [现有案例对读](./现有案例对读.md) 通过 4 个已有案例学习条形统计、嵌套分区、路线示意和词频。

新收录案例含统计图时，先在 02 的案例模板 B 栏写清使用的图和计算，再按需在 03 记录细节并双向链接。资料只够读图时，写清可从图面看到的事实与待核项。02 保存案例主档，03 记录统计部分。
