## 怎么给一张图分类

在五种基础类型里选一个**主归属**，看的是信息之间的主关系。表现形式可以选多个，帮助查找画法。例如 [PlayStation 演变图](../02-信息图形类型案例/03-时间轴型-Timeline/案例/CASE-001-PlayStation演变/分析.md) 的主归属是「编年型」，表现形式是「时间轴型」。按 A–Z 排列的清单，其主归属可以是「字母表型」。

## 新增案例时怎样更新

1. 在 [02 案例索引](../02-信息图形类型案例/README.md) 里查重。按 [案例分析模板](../02-信息图形类型案例/案例分析模板.md) 新建一个案例，记录出处、可核验的图面证据、主归属和表现标签。
2. 在同一次提交里，更新案例索引、对应的表现说明和 [01 理论文档](../01-信息图形数据逻辑/) 的案例链接。一个案例只保留一份主档，其他说明通过链接引用。
3. 新例子如果增加了有效方法、例外或反例，就把变化写进对应文档，并链接证据。只提供了另一张相似的图时，补案例链接即可。说明中区分原图可见内容、对数据结构的推测和设计建议。
4. 图片如已获公开归档授权，放在 02 对应案例目录。外部参考作品可以保留原作链接。01 通过文字链接引用案例。

案例主要来自此前选定的 SCMP 印刷图集和同版公开资料。少数表现形式采用可核验的学术或作者资料，已在案例页标明。具体原则会随新案例或反例补充。
