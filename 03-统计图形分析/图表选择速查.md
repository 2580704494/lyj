# 图表选择速查

先把想回答的问题写成一句话。例如「哪一类最多」「什么时候变化最大」或「这些点集中在哪里」。再检查数据表的一行表示什么。下面是常用选择，可按实际任务取舍。

| 想回答的问题 | 至少需要的字段 | 优先考虑 | 图面线索和容易混淆的地方 |
|---|---|---|---|
| 哪些类别多、哪些少？ | 类别、数值或可统计的条目 | 条形图／柱状图 | 条长表示数值，通常从零开始；多组比较使用同一尺度。 |
| 一段时间内怎么变？ | 时间、同一口径的数值 | 折线图 | 用位置表示日期，非等间隔按真实时间画。缺测可断开或标出。 |
| 事情何时发生或持续多久？ | 事件、时间，必要时有结束时间 | 事件时间轴／区间条 | 只有先后顺序时可用阶段图；间距代表时长时才用等比例时间轴。 |
| 整体由哪些部分组成？ | 类别、数值、明确总量，多组时再加组别 | 100% 堆叠条／少分类饼图 | 同一整体中的部分要互斥。需精确比较各组时，优先条图或数值表。 |
| 同类对象里数值如何分布？ | 一组原始数值或按区间的计数 | 直方图 | 箱宽和区间影响结论。区间等宽时可用频数作柱高；不等宽时用频数密度让面积表示频数。 |
| 多组的中位数和分散程度如何？ | 组别、每个样本的数值 | 箱线图／点图配中位数标记 | 中线通常是中位数。说明须线规则、样本量和离群点口径。 |
| 两项数值是否一起变化？ | 同一对象上成对的两个数值 | 散点图 | 一点对应一组观测。关系、异常点和分组可以观察，单靠图不能推出原因。 |
| 哪些组合更集中？ | 行类别、列类别、格内指标 | 热力图 | 色深对应格内值，统一色标；缺失与零分别标。 |
| 谁属于谁？各部分有多大？ | 节点、上级 ID、可加总的数值（可选） | 树图／树状矩形图 | 边界表示包含。需要表达权重时再用面积，避免同一条记录重复计入。 |
| 地点在哪里？不同区域有什么差异？ | 地点或区域 ID、可选数值与分母 | 点位地图／比例符号图／分级设色图 | 点位用于定位。比总量可用比例符号；用设色比较强度时说明分母与分级。 |
| 数量从哪里流到了哪里？ | 起点、终点、流量、单位 | 桑基图 | 线宽对应流量。只有地点顺序而没有流量时，用路线示意。 |
| 文本里哪些词最常出现？ | 文本语料或词项与计数 | 条形图／词云 | 条形图便于精确比较；词云用字号突出词频时，要说明清洗与字号规则。 |
| 需要逐项查准数字？ | 条目、精确数值、单位 | 表格 | 给出排序和单位；需要一眼看趋势时再配图。 |

## 从表到图

以你的《拆开之后》为例，可以先让**一行代表一个包装部件**，记录部件、材质与实测重量。想比较材质的件数，就按材质计数后画条形图；想比较每个部件的精确重量，就保留原始表或另做排序图。两张图回答的是不同问题，字段也随之改变。

起稿前核对 **一行代表什么、用什么单位、分母是什么、缺失怎么记**。再说明颜色、长短或面积对应什么数据。数据条件不完整时，先在表里标出待补字段。
