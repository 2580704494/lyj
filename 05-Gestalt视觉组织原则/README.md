# 05 Gestalt 视觉组织原则

这一章从信息图形出发，研究人怎样把位置、颜色、路径、边界和动态变化组织成一组元素、一个形状或前景与背景。

[概念与分类框架](./00-Gestalt概念与分类框架.md)说明为什么本章收录 12 项，以及这些原则如何对应仓库里的数据逻辑、图形形式和统计编码。
