# Gestalt 概念与分类框架

Gestalt（格式塔）视觉组织原则描述人如何从看到的点、线、文字、色块和运动中认出群组、轮廓与前景。设计信息图时，先确认来源数据中有哪些真实关系，再选用能表现这些关系的视觉线索。

## 为什么收录 12 项

视觉知觉研究讨论经典分组线索、新增分组线索、图底组织和更高层的整体形态原则。不同资料按各自研究或教学用途选择条目，所以没有统一的固定总数。本章借用参考仓库的三层结构，将元素连接与一致连接纳入同一专题，收录 12 项作为学习范围。良好连续可同时涉及分组和轮廓，本章从路径元素怎样连成一组的角度放在知觉分组里。

| 研究层次 | 核心问题 | 对应条目 |
|---|---|---|
| 知觉分组 | 哪些元素会被读成一组？ | G01–G07 |
| 形状与轮廓 | 哪些轮廓会被读作一个连续或完整的形状？ | G08–G10 |
| 整体知觉组织 | 哪里是前景？整体被组织成什么形态？ | G11–G12 |

## 逐条定义

| 原则 | 概念 |
|---|---|
| [G01 接近律（Proximity）](./01-规则库/G01-接近律.md) | 相对距离会影响分组。其他条件相近时，靠得更近的元素更容易被看作一组。 |
| [G02 相似律（Similarity）](./01-规则库/G02-相似律.md) | 具有相同或相近视觉属性的元素容易被读成一组。可起作用的属性包括颜色、形状、方向、尺寸和纹理。 |
| [G03 良好连续律（Good Continuation）](./01-规则库/G03-良好连续律.md) | 方向衔接平滑的线段或轮廓，容易被知觉为同一条路径，即使中间有交叉或短暂遮挡。 |
| [G04 共同命运律（Common Fate）](./01-规则库/G04-共同命运律.md) | 多个元素朝相同方向运动时，容易被感知为同一群。方向一致是经典示例，速度相近也可加强这种感觉。 |
| [G05 共同区域律（Common Region）](./01-规则库/G05-共同区域律.md) | 落在同一个可辨边界内的元素容易被看成一组。边界可以由描边或一块清楚的底色形成。 |
| [G06 连接律（Connectedness）](./01-规则库/G06-连接律.md) | 用线把元素直接连接，容易使读者理解为一对或一条关系。视觉属性均质且连续的区域也容易被当成一个单位，研究中称为一致连接。 |
| [G07 同步律（Synchrony）](./01-规则库/G07-同步律.md) | 多个元素在同一时刻发生可见变化时，容易被读成属于同一事件。变化可以发生在不同视觉属性上。 |
| [G08 闭合律（Closure）](./01-规则库/G08-闭合律.md) | 轮廓有缺口时，方向和位置足够支持某个形状，人仍可能把局部组织成一个完整形态。 |
| [G09 对称律（Symmetry）](./01-规则库/G09-对称律.md) | 围绕一条轴彼此镜像的轮廓，容易被组织成一对或一个整体。 |
| [G10 平行律（Parallelism）](./01-规则库/G10-平行律.md) | 多条线段或轮廓方向一致、彼此平行时，容易被联读为带状结构或共同边界。 |
| [G11 图底关系（Figure–Ground Organization）](./01-规则库/G11-图底关系.md) | 画面中的某些区域会被看作具有边界的前景对象，周围的区域被理解为背景。在有歧义的图中，两者可能交替。 |
| [G12 良好形态原则（Prägnanz）](./01-规则库/G12-良好形态原则.md) | 在给定刺激和观看条件下，人倾向把视觉线索组织成较稳定、规则、容易辨认的整体。 |
