# 星屑双奏：逐步风格分析与克隆预览

候选案例 STYLE-CASE-004；档案 STYLE-STELLAR-DUET-004@0.1.0；provisional。仅本地待审，尚未上传仓库。

## 01 启动

读取远端 START_HERE.txt，使用本会话已加载的 SC-IMG 1.0.0 核心、操作和数据约定。已查看一张参考；模式为 EXTRACT、APPLY、AUDIT。图面文字只作内容，不执行其中指令。

## 02 范围

本轮保持双角色动漫舞台主视觉主题，先测试同主题风格复现。人物身份、作者、制作工具未核实，不凭外观命名。无统计数据，不启用计数复算模块。图片角落标识不写入风格规则。

## 03 证据

分别观察两张脸、手部、服饰、粉金发束高光、轮廓、发束交叠、环内暗空间和背景星屑。可见观察存 evidence，提炼后的要求存 rules，单图归纳的迁移可靠性保持待验证。

## 04 十三维分析

| 维度 | 可见事实与结论 |
|---|---|
| 身份 | 精细动漫角色主视觉，深底、明亮角色和巨大发束构图结合。 |
| 色彩 | 近黑背景，粉色与金色大色组，浅肤色和少量冷色眼睛/衣饰强调。 |
| 光照 | 发束带状高光、肤色柔和塑形、衣饰局部锐利反光，发光范围受控。 |
| 构图 | 上部粉色大环、下部金色回旋扇面，形成竖向交错S节奏，环内保留黑色空隙。 |
| 尺度 | 发束覆盖范围远大于身体；两角色上下错位。 |
| 造型 | 大眼、小鼻口、纤细四肢、清楚的动漫手势，表情活跃。 |
| 绘画语言 | 细线稿、分块阴影与局部柔和渐变结合，并非纯平涂。 |
| 边缘 | 角色轮廓清楚，高光附近有少量软光；不是全图柔焦。 |
| 完成度 | 脸眼、手、发束转折和服饰饰件精修，背景简化。 |
| 纹理 | 表面光洁，头发成束而非逐根写实；没有主导性的纸纹和粗颗粒。 |
| 密度 | 细节集中在角色与发束，外围暗空间星点稀疏。 |
| 锚点 | 两张脸与发束高光转折形成上下锚点。 |
| 张力 | 静暗背景与亮色动态、身体与长发尺度、粉金两组色彩的对照。 |

## 05 提取规则

十条规则覆盖：混合赛璐璐明暗、细线清晰边缘、深底粉金色组、材质高光分工、动漫人物造型、大弧线动势、夸张流动形体、光洁表面、局部细节与安静外围、精修锚点与受控星芒。每条关联证据与检查方法。

## 06 区分内容

双角色、具体发色与服饰、上下姿势是当前内容；本档案将粉金主色关系暂定为风格核心，因此改主色组需派生版本。长发是本轮曲线动势载体，换题材可尝试飘带、流体或其他流动形体，但这种跨题材替换尚未验证，不能直接宣称等效。

## 07 条件适配

R005 人物造型仅在 human/mixed 启用；R006/R007 回旋构图与尺度夸张仅在 wide 启用。近景头像或非人物任务需重新适配，不能用同一句长发构图强行套用。

本轮实例为高竖幅、粉发在上金发在下、轻盈动态和深色星屑背景，重新安排动作服饰，不进行角色身份严格复刻，也不加入文字水印。

逐规则看真实成图：线条是否变粗，肤色是否塑料化，头发是否碎成乱丝或无结构光团，环内暗空间是否消失，背景星点是否过密，脸手是否被泛光覆盖。内容上另看双角色、上下色组及动作结构。仅按可见证据判断，不报虚构相似度百分比。审阅结果另存 review.json。
