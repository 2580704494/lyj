## 04 十三维分析

| 维度 | 可核对的图面特征 |
|---|---|
| 身份 | 极细线装饰性时装人物，深红底、平面实形和局部微纹样结合。 |
| 色彩 | 深红占主导；黑色小块、赭金细纹、象牙白线点各有分工，未进行精确取色。 |
| 光照 | 亮暗来自色彩对比，未见主导性的自然光塑形或投影。 |
| 构图 | 狭长中轴对照宽展裙框，头饰圆与底部倾斜椭圆呼应，周围保留大空域。 |
| 尺度 | 面孔小、颈肢极长、躯干窄、头饰和裙框宽度夸大。 |
| 造型 | 非写实细杆状肢体与角状关节，姿态不对称。 |
| 绘画语言 | 精密细线、少量黑色实形、局部金色微纹样，不能泛称厚重金属画。 |
| 边缘 | 清楚细轮廓，没有主导性光晕；部分极细线在背景中较弱。 |
| 完成度 | 装饰区域局部精细，头饰故意低对比，非全图同等显眼。 |
| 纹理 | 纹样主要在金色小区域，背景和平面黑块相对平整。 |
| 密度 | 局部密纹与大面积空红对照；裙框内部没有填满布料。 |
| 锚点 | 圆盘、髋部汇线、白色珠链和鞋部曲线构成停顿。 |
| 张力 | 细与宽、实与空、角折与弧线、局部繁密与整体疏朗。 |

## 05 规则提取

十条规则覆盖主色分工、细线建形、线宽、人物比例、主轴与弧形构图、局部密纹、平面纹理、非写实光照、珠点节奏与低对比层级。各有证据、允许变化和检查项。

## 07 任务适配

人物极端比例仅在 human/mixed 条件下启用。当前实例保留单个人物、圆盘头饰、黑金分区、空裙框和倾斜椭圆。允许姿态细节重组，但不得将空框变成实心华丽礼服，或将暗圆盘变成金色光环。
