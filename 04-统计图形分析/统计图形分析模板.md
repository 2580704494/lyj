# 统计图形分析模板

用于分析 02 已收录作品中的一张主图或局部。可以直接在 02 案例模板 B 栏摘要记录；有具体计算或多个图要比较时，再写成独立分析并加链接。

| 栏目 | 要记什么 |
|---|---|
| 关联案例与范围 | CASE 编号、分析哪张图或哪个局部、原作链接和数据出处。 |
| 想回答的问题 | 是比较数量、观察变化、找分布，还是定位路线？ |
| 数据表 | 每行代表什么，记录哪些类别、时间、地点和数值。标明数据单位、样本或地理范围。 |
| 数据处理 | 记录筛选、去重、分组、合并规则和缺失处理。 |
| 计算方法 | 写明是计数、合计、均值、比例、变化率还是其他统计。比例交代分子和分母，均值交代是否加权。 |
| 视觉编码 | 具体写出位置、线长、点大小、面积、颜色或字号分别表示什么。记录坐标尺度、范围和图例。 |
| 读到的结论 | 用一句话写出这张图能支持的发现。 |
| 证据与限制 | 分开记录图面可读、可用原始数据复算与待核内容。给出已核对的资料位置。 |
| 可以改进什么 | 提出一项具体修改并说明目的，例如标明缺测、统一尺度或补上分母。 |

### 提交前检查

- 指标、单位、样本范围、时间范围与图上结论一致。
- 缺测与实际为零有不同标记。分类发生重叠时，合计和比例按各自口径。
- 用同一尺度进行需要的比较，图形大小未被装饰性透视改变。保留来源并检查读者能否由图面找到判断依据。
