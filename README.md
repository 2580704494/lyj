**启动入口：[START_HERE.txt](./START_HERE.txt)** · **[风格分析与克隆系统](./06-风格分析与克隆系统/README.md)** · **[每一步怎么做](./06-风格分析与克隆系统/逐步操作指南.md)**

| 模块 | 负责什么 | 交给后续模块的结果 |
|---|---|---|
| [01 信息图形数据逻辑](./01-信息图形数据逻辑/README.md) | 判断编年、层级、编目、字母表、地理关系 | 真实关系、字段、排序与不可改变的信息 |
| [02 信息图形类型案例](./02-信息图形类型案例/README.md) | 选择表现形式，分析原作证据 | CASE 引用、图形类型、阅读任务 |

## 直接开始

给能读取本仓库的大模型发送：

> 读取仓库根目录 START_HERE.txt，启动风格分析和克隆系统。先确认加载情况，再分析我提供的参考图；输出可复用的中文 JSON、英文 JSON、中文简易提示词、英文自然语言提示词。涉及信息图时，同时执行仓库联动约束。

网页版模型：下载并上传 [WEB_START.txt](./06-风格分析与克隆系统/WEB_START.txt)，发送“启动风格分析和克隆系统”，再提供参考图或完整风格档案。要联动其他章节，再附上 [仓库联动协议](./06-风格分析与克隆系统/仓库联动协议.md) 及本次用到的章节。单文件可独立分析风格，但没有携带全部案例库。

纯插画走 `参考图 → 06 提取/适配 → 四版输出 → 成图审计`；信息图走 `01 → 02 → 按需 04/03 → 05 → 06 → 04/03/05 与 06 联合审计`。不得为了风格相似改变数据事实。

本仓库提供文档工作流和离线辅助工具。图像理解与生成由实际使用的大模型/生成工具完成；软件检查通过不表示视觉克隆已通过。查看 [联动协议](./06-风格分析与克隆系统/仓库联动协议.md)、[完整示例](./06-风格分析与克隆系统/联动示例.md) 和 [验证记录](./06-风格分析与克隆系统/仓库验收报告.md)。
