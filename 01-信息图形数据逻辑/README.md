# 01 信息图形数据逻辑

先判断信息之间的主关系，再选择画法；为后续风格迁移锁定事实关系。

| 主关系 | 文档 |
|---|---|
| 日期、阶段与先后 | [编年型](./01-编年型信息图形概念定义.md) |
| 隶属、包含与等级 | [层级型](./02-层级型信息图形概念定义.md) |
| 类别与对象 | [编目型](./03-编目型信息图形概念定义.md) |
| 词条、检索键与排序 | [字母表型](./04-字母表型信息图形概念定义.md) |
| 地点、边界与路线 | [地理图形](./05-地理图形信息图形概念定义.md) |

## 交给风格系统什么

记录主归属、最小记录单位、字段与来源；把日期顺序、真实层级、类别归属、检索排序、地理位置等转成可核对的锁定项。证据缺失的关系标为待核，不能让风格系统补造。

先到 [02](../02-信息图形类型案例/README.md) 选择表现形式，再按需到 [04](../04-统计图形分析/README.md) 核算数据、[03](../03-ISOTYPE信息图/README.md) 设定图符编码、[05](../05-Gestalt视觉组织原则/README.md) 检查组织，最后交给 [06 风格系统](../06-风格分析与克隆系统/README.md)。

换风格后若顺序、归属或路线改变，退回本模块复核。数据关系不能作为装饰自由变动。具体交接格式见 [仓库联动协议](../06-风格分析与克隆系统/仓库联动协议.md)。
