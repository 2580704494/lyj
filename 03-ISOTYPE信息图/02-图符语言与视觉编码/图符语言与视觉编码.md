# 02 图符语言与视觉编码

做数量比较时，先确定一个图符代表多少，再用**相同大小的同类图符**重复出现的次数表达数量。图符的外形帮助识别对象，图例让读者把图符换算回数据。[Isotype Revisited 方法说明](https://isotyperevisited.org/2012/08/introduction.php)

| 视觉元素 | 承担的信息 | 画图时怎样做 |
|---|---|---|
| 图符外形 | 统计的是什么 | 用可辨认的轮廓，例如用汽车轮廓表示机动车 |
| 图符个数 | 统计了多少 | 各组使用同一图例单位，数据增加时增加图符 |
| 位置和对齐 | 哪些对象或时期可直接比较 | 各组对齐，按类别或时间分行，并在对应处标名 |
| 色彩 | 区分明确的类别或地区 | 颜色含义查原图或写在图例中，必要时同时配组名 |
| 线与间距 | 分隔组别，连接标注 | 让分隔线、引线和数据行容易区分 |
| 单位和文字 | 交代每个图符代表多少，以及指标范围 | 单位靠近图形，精确数值或取整规则可在该组旁标明 |

复核时先看图例，再挑一行数图符。用「图符数 × 单个图符代表的数量」核对原始数值。若使用部分图符，需明示一部分代表多少。实测零值可标为 0。待测或缺失另行标注。
