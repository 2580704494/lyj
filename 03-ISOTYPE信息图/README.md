# 03 ISOTYPE 信息图

这个专题围绕一个问题展开。怎样把一组数字变成读者能辨认、能数出来的图形？ISOTYPE 在本仓库作为一种基础设计方法。分析作品时，仍按它的主要数据关系判断基础类型。
