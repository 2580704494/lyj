# CASE-017 · 200 geniuses of the millennium

**出处与范围**　Katie Yue、Marcelo Duhalde；作者和原题按 SCMP 获奖记录。

**来源**　[SCMP 印刷版面](https://multimedia.scmp.com/culture/article/SCMP-printed-graphics-memory/img/graphics/geniuses.jpg) · [SCMP 作品记录](https://corp.scmp.com/our-awards/2025)

**主归属**　编年型。 **表现标签**　编年编目复合型。 **案例来源**　SCMP 印刷图集。

| 分析维度 | 观察 |
|---|---|
| A 数据逻辑 | 不同人物被组织到年代参照上，并以分轨、不同色彩与标注辅助分类浏览。 |
| B 统计图形与计算 | 可用区间条理解人物所处时段，版面上精确语义以原图图例为准。名单不能代表每个年代的完整人口统计。 |
| C 视觉编码 | 位置和条带传递年代，类别与颜色使用规则需要与图例对应。 |
| D 数据／信息架构 | 可用「人物、起点年代、结束年代、分组、出处」组织，每行一人。 |
| E 视觉叙事 | 先选一个年代范围，再追踪同一范围内的人物和分组，也可沿某个组跨年代看。 |

**可迁移原则**　时间与分类同时出现时，两种关系要用不同视觉通道，读者才能在两个方向中切换。
