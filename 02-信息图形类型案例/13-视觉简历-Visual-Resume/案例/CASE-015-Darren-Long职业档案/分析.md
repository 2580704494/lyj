# CASE-015 · Darren Long at the Post

**出处与范围**　Adolfo Arranz 的 SCMP 印刷作品。原作用途为职业人物纪念，本档记录它作为视觉简历的近例。

**来源**　[SCMP 印刷版面](https://multimedia.scmp.com/culture/article/SCMP-printed-graphics-memory/img/graphics/darren.jpg) · [SCMP 职业资料](https://www.scmp.com/author/darren-long) · [刊载 SCMP 纪念报道的 SND 页面](https://snd.org/in-memory-of-darren-long/) · [SCMP 作品记录](https://corp.scmp.com/2022-awards/)

**主归属**　编目型。 **表现标签**　视觉简历。 **案例来源**　SCMP 印刷图集 · 职业档案近例。

| 分析维度 | 观察 |
|---|---|
| A 数据逻辑 | 以同一人物为核心，将任职、团队成果和轶事组织在一个版面。按信息板块的组织关系归为编目。 |
| B 统计图形与计算 | 团队获奖和个人经历须分开理解。版面数字以原版注释为准，纪念报道可补充统计口径。 |
| C 视觉编码 | 大肖像先帮助定位人物，图形与数值标注用于成果记录，小幅插画指向附加叙事。 |
| D 数据／信息架构 | 可按「人物、任职或项目、时段、职责、成果归属、来源」整理。 |
| E 视觉叙事 | 先读人物身份，再读专业成果，最后浏览补充细节。 |

**可迁移原则**　作品集中介绍团队成果时，明确人物的贡献以及成果属于个人还是团队。
