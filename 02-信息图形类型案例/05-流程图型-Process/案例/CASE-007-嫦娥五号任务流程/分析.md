# CASE-007 · To the moon and back

**出处与范围**　Dennis Wong，《南华早报》。

**来源**　[SCMP 印刷版面](https://multimedia.scmp.com/culture/article/SCMP-printed-graphics-memory/img/graphics/change5.jpg) · [SCMP 作品说明](https://store.scmp.com/products/infographics-to-the-moon-and-back)

**主归属**　编年型。 **表现标签**　流程图型。 **案例来源**　SCMP 印刷图集。

| 分析维度 | 观察 |
|---|---|
| A 数据逻辑 | 地球与月球之间的任务阶段通过路径组织，读者可以顺着阶段看推进。 |
| B 统计图形与计算 | 轨迹主要解释任务路线与阶段。图上距离不能直接当作旅行距离或持续时间。 |
| C 视觉编码 | 路径、天体和飞行器轮廓共同定位；阶段文字就近解释任务的变化。 |
| D 数据／信息架构 | 一行一个阶段。字段可用阶段、前置节点、对象、位置或状态、资料出处。 |
| E 视觉叙事 | 先认出任务的目的与两端，再沿路径从出发读到返回。 |

**可迁移原则**　需要解释复杂过程时，先让读者沿箭头走通整条路径，再补个别节点的技术细节。
