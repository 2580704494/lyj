# 05 流程图型 · Process

用节点、箭头和阶段说明事物怎样从一个状态进入另一个状态。普通顺序可沿一条线读，有条件选择的流程需要为每条出口标明条件。

## 设计方法

- 先写清每个节点描述的是动作、决策还是结果。把节点标题改成能一眼读懂的短词。
- 用有方向的连接表达先后或依赖。独立的旁注用另一种线样，避免读成流程分支。
- 并行、回退、等待或异常情况在实际流程里存在时再画入。日期和持续时间可另加标注。
