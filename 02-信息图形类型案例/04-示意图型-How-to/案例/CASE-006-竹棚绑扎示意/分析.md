# CASE-006 · Why Hong Kong uses bamboo scaffolding · 绑扎示意

**出处与范围**　SCMP Graphics 专题；分析范围为绑扎示意局部。

**来源**　[SCMP 原专题](https://multimedia.scmp.com/infographics/culture/article/3183200/bamboo-scaffolding/) · [SCMP 相关报道](https://www.scmp.com/lifestyle/arts-culture/article/3191778/why-hong-kong-still-uses-bamboo-scaffolding-construction)

**主归属**　编年型。 **表现标签**　示意图型。 **案例来源**　SCMP 同站专题 · 局部。

| 分析维度 | 观察 |
|---|---|
| A 数据逻辑 | 节点是连续的操作阶段，前一阶段形成的竹杆及绑带状态供下一阶段继续操作。 |
| B 统计图形与计算 | 重点是部件位置和动作关系。分析这个局部不需要拿示意比例计算承重。 |
| C 视觉编码 | 近景说明接合的位置。读图时把部件轮廓、动作标记、解释文字分别看。 |
| D 数据／信息架构 | 可建操作表，一行一个步骤，字段为步骤号、部件、动作和可观察结果。 |
| E 视觉叙事 | 先认出竹杆和绑带，再顺序看连接如何形成。该分析用于图形设计研究。 |

**可迁移原则**　想教读者一个具体动作，就在同一视角里展示动作前后的可见差别。
