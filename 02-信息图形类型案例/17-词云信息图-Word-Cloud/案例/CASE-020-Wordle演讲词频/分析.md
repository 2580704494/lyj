# CASE-020 · Participatory Visualization with Wordle · 图 2

**出处与范围**　Fernanda B. Viégas、Martin Wattenberg、Jonathan Feinberg，2009 年发表于 IEEE TVCG。本档分析论文图 2 的词云示例。

**来源**　[论文正式记录](https://research.ibm.com/publications/participatory-visualization-with-wordle) · [作者公开的图 2 与全文（查找 Fig 2）](https://www.researchgate.net/publication/38015440_Participatory_Visualization_with_Wordle)

**主归属**　编目型。 **表现标签**　词云信息图。 **案例来源**　补充来源 · 学术原图。

| 分析维度 | 观察 |
|---|---|
| A 数据逻辑 | 以同一份演讲文本中的词项为单位，按词项统计出现次数。图 2 将同一语料的 Wordle 与传统标签云并置。 |
| B 统计图形与计算 | 论文说明 Wordle 的字号与词频线性相关。字号和字形铺开的面积是不同读数。 |
| C 视觉编码 | 字号承担词频，位置、旋转和色彩主要帮助构图。同样长的一段文字在不同版本里可能占不同位置。 |
| D 数据／信息架构 | 可用「归一化词项、次数、语料名称、处理规则、字号映射」记下分析需要的字段。 |
| E 视觉叙事 | 先从大字找到高频词，再用数字表或原文上下文核对选择性阅读带来的偏差。 |

**可迁移原则**　当词云用于定量分析时，公开字号规则与语料范围，让读者知道哪些视觉特征能用于比较。
