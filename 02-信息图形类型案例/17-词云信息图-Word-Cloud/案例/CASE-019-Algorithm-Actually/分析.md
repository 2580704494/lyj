# CASE-019 · Algorithm Actually

**出处与范围**　Natalie Wong，2023 年。SCMP 报道过的独立艺术项目。

**来源**　[作者项目页与作品画面](https://www.nataliewong.work/work/algorithm-actually) · [SCMP 对作品的报道](https://www.scmp.com/lifestyle/arts-culture/article/3231740/coffee-meets-bagel-dating-app-chat-turned-prize-winning-digital-art-hong-kong-based-artist-reflects)

**主归属**　编目型。 **表现标签**　词云信息图。 **案例来源**　补充来源 · SCMP 报道与作者项目。

| 分析维度 | 观察 |
|---|---|
| A 数据逻辑 | 从一段聊天中筛选高频词，把词项作为视觉元素。这里只分析词项生成和集合，整段动态另有时间和语义叙事。 |
| B 统计图形与计算 | SCMP 报道提到用了 15 个常见词。公开说明支持按常见度筛选，字号的精确权重映射未证实。 |
| C 视觉编码 | 文字本身构成三维动态画面。字母的移动和重组承担主题表达。 |
| D 数据／信息架构 | 可用「词、出现次数或筛选规则、语料范围、画面阶段、出处」描述。原始私密聊天不录入。 |
| E 视觉叙事 | 先辨识词，再观察字母如何拆分和组合，最后读作者解释。 |

**可迁移原则**　分清用词频筛选词和用字号表现词频；后者需要有明确的映射证据。
