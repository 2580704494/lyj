## 基础设计方法

[ISOTYPE｜基础设计方法](./ISOTYPE-基础设计方法/00-标签说明.md)。阅读图形符号的数量编码规则、历史案例和复算示例。

每件案例保留一个编号和一份分析。每个案例在相应标签的 `案例/` 下用 `CASE-编号-作品名/分析.md` 存放。引用公开作品时，在分析页保留原作链接；有获准归档的图时，把 `原图.png` 放进该案例文件夹。
