# CASE-010 · Coming to the light · 根特祭坛画照片与放大细节

**出处与范围**　Adolfo Arranz 的 SCMP 背页作品；本档分析照片及局部对照区。

**来源**　[SCMP 印刷版面](https://multimedia.scmp.com/culture/article/SCMP-printed-graphics-memory/img/graphics/vaneyck.png) · [作者案例页与局部图](https://www.perdigallos.com/ghent-altarpiece)

**主归属**　编目型。 **表现标签**　图片式。 **案例来源**　SCMP 印刷图集 · 局部。

| 分析维度 | 观察 |
|---|---|
| A 数据逻辑 | 这个局部按画板和细节对照规则组织。整版还说明修复流程，局部与整版的主关系可以不同。 |
| B 统计图形与计算 | 照片提供可见的形状、色彩和纹理证据。图中观感不直接换算成修复程度。 |
| C 视觉编码 | 整件祭坛画影像用来定位部位，局部影像帮助读者看清羔羊等细节，示意图补足材料和画层关系。 |
| D 数据／信息架构 | 建议用「画板／部位、影像版本、细节、对应文字、来源」记录观察。 |
| E 视觉叙事 | 先认出整体，再跟着标注看细节，最后读解释。 |

**可迁移原则**　给每幅细节图一个清楚的整体定位，能够让照片成为可核对的证据。
