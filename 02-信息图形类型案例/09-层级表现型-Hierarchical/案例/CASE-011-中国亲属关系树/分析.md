# CASE-011 · Family tree: a guide to the Chinese kinship system

**出处与范围**　Kaliz Lee，《南华早报》。

**来源**　[SCMP 印刷版面](https://multimedia.scmp.com/culture/article/SCMP-printed-graphics-memory/img/graphics/chinesekinship.jpg)

**主归属**　层级型。 **表现标签**　层级表现型。 **案例来源**　SCMP 印刷图集。

| 分析维度 | 观察 |
|---|---|
| A 数据逻辑 | 亲属称谓要通过与参照人的辈分和关系来确定。看树枝的连接对象比只看称谓更清楚。 |
| B 统计图形与计算 | 主图使用关系示意，读者无须依据节点大小推算家族人数。 |
| C 视觉编码 | 分支线表达延伸关系，组别色和相邻位置帮助区分不同支系。按辈分阅读的节点保持可找性。 |
| D 数据／信息架构 | 可拆成关系节点表和关系边表，分别记称谓、辈分、上一级或连接对象。 |
| E 视觉叙事 | 先找参照人或已知亲属，再沿分支读到目标称谓。 |

**可迁移原则**　层级图的实用判断是读者能否从一个条目追溯到它属于的上一级。
