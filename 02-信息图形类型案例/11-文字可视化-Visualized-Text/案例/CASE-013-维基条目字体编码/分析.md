# CASE-013 · Using Typography to Expand the Design Space of Data Visualization · 图 17

**出处与范围**　Richard Brath、Ebad Banissi，2016 年发表于《She Ji》。这是学术补充案例。

**来源**　[作者论文全文（查找 Figure 17）](https://researchportal.lsbu.ac.uk/files/6361819/1f4d3bbb_ExpandDesignSpace-20160417.pdf) · [研究机构说明](https://uncharted.software/research/using-typography-to-expand-the-design-space/)

**主归属**　编目型。 **表现标签**　文字可视化。 **案例来源**　补充来源 · 学术原图。

| 分析维度 | 观察 |
|---|---|
| A 数据逻辑 | 研究样图把维基百科文章并列，每行对应一篇文章，比较各篇的属性。 |
| B 统计图形与计算 | 使用文字格式覆盖长度承载量值。研究文献标示字段，但版面无法替代原始访问记录。 |
| C 视觉编码 | 粗体覆盖长度表示文章长度，下划线为浏览量；大小写变化表示新旧程度，斜体范围表示作者数量。 |
| D 数据／信息架构 | 可用「文章名、内容摘要、文章长度、浏览量、发布新旧、作者数」记录每条数据。 |
| E 视觉叙事 | 先辨认行标题，再按图例只读一种文字样式，跨行比较该指标。 |

**可迁移原则**　文字同时承担标题与数据时，读者要能看清文字，也要有办法辨认编码。
