# CASE-018 · Kai Tak Stadium: Hong Kong, it’s showtime

**出处与范围**　Lau Ka-kuen、Marcelo Duhalde；案例分析立体场馆与总平面图的衔接。

**来源**　[SCMP 印刷版面](https://multimedia.scmp.com/culture/article/SCMP-printed-graphics-memory/img/graphics/kaitaksportspark.jpg) · [SCMP 专题局部图](https://multimedia.scmp.com/infographics/sport/article/3300482/kai-tak-sports-park/html/seating-area.html)

**主归属**　地理图型。 **表现标签**　三维型。 **案例来源**　SCMP 印刷图集。

| 分析维度 | 观察 |
|---|---|
| A 数据逻辑 | 先用总平面表达体育园内各场馆的位置，再用立体图呈现重点场馆可见结构。 |
| B 统计图形与计算 | 空间关系主要通过立体形态和位置来读。座位规模等数值以标注为准。 |
| C 视觉编码 | 立体视角帮助辨认场馆整体，平面位置与局部图补充场地层级和细节。 |
| D 数据／信息架构 | 可建立「场馆或部位、园内位置、结构所在层、对应视图、出处」观察表。 |
| E 视觉叙事 | 先定位场馆，再查立体图和部位特写。 |

**可迁移原则**　立体图适合讲空间结构，同时提供平面图能让读者找准方向。
