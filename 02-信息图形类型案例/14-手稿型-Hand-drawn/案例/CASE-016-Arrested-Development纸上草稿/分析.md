# CASE-016 · Arrested development · 纸上草稿与成品对照

**出处与范围**　Adolfo Arranz；分析对象为作者访谈中同时展示的草稿和印刷成品。

**来源**　[作者访谈及稿图对照](https://nightingaledvs.com/on-the-success-of-the-south-china-morning-post-infographics-team/) · [SCMP 印刷成品](https://multimedia.scmp.com/culture/article/SCMP-printed-graphics-memory/img/graphics/arrested.png) · [SCMP 作品及署名确认](https://www.scmp.com/news/hong-kong/society/article/3114847/south-china-morning-post-wins-gold-global-design-competition)

**主归属**　编目型。 **表现标签**　手稿型。 **案例来源**　SCMP 作品 · 原始手稿对照。

| 分析维度 | 观察 |
|---|---|
| A 数据逻辑 | 作者先用草稿划定不同统计与叙事区，成品按不同观察维度组织事件相关记录。 |
| B 统计图形与计算 | 草稿可用来观察统计图的预留位置；数值和计算以成品及其来源为准。 |
| C 视觉编码 | 粗线、草书和框线表达版面关系。通过右侧完成版对照，辨认哪些线条变成正式的编码。 |
| D 数据／信息架构 | 可用「草稿区域、预定信息、成品对应区、证据、修改原因」做对照记录。 |
| E 视觉叙事 | 按标题、主图、补充区的顺序对照两个版本，观察读图入口如何形成。 |

**可迁移原则**　将草稿上的构图决策与成品的数据表达分开记录，比较才有可核对的依据。
